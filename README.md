# KuArte · sample preview

Three responsive pages that adapt to phone, tablet and laptop:

- `index.html`: Home
- `designs.html`: Book by design (filter by style)
- `map.html`: Techs near you (list and map; tap a pin or a card to select, sort by distance, rating or price)

Everything else shows a "coming soon" message. All names and prices are sample data. Photos are in `assets/photos/`; replace them keeping the same file names.

## Deploy to Vercel

1. Create a new GitHub repository and upload everything inside this folder (not the folder itself).
2. On vercel.com, choose Add New → Project → import the repository.
3. Leave Framework Preset as "Other" and the build settings empty. Click Deploy.

Deploy it as its own Vercel project so it gets its own link.
